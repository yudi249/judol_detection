# Thesis

Area penulisan akademik skripsi.

- `proposal/`: proposal dan hasil konversi Markdown.
- `chapters/`: draft bab skripsi.
- `figures/`: gambar, diagram, wireframe, dan screenshot.
- `tables/`: tabel evaluasi dan tabel eksperimen.
- `references/`: BibTeX atau daftar referensi.
- `final/`: naskah final dan lampiran.
