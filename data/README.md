# Data

Area ini menyimpan dataset penelitian.

- `raw/`: data awal dari Telegram, YouTube, dan Twitter/X.
- `interim/`: data setelah filter awal, deduplikasi, dan pembersihan kasar.
- `processed/`: dataset final untuk train, validation, dan test.
- `adversarial/`: dataset hasil manipulasi Unicode.
- `annotation/`: pedoman labeling, hasil anotator, dan perhitungan Cohen's Kappa.

Dataset mentah dan hasil olahan besar tidak dilacak Git secara default.
