# Browser Extension

Prototipe browser extension Manifest V3 untuk:

- Memindai elemen teks pada DOM.
- Mengirim batch teks ke REST API.
- Menerapkan blur dan overlay peringatan pada teks promosi judol.
- Menyorot karakter Unicode mencurigakan.
- Menyimpan statistik sesi dan riwayat deteksi di browser storage.
